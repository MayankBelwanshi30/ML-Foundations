# Machine Learning Models Repository

## Description

This repository is a comprehensive collection of **Machine Learning Models** built using Python and scikit-learn. It serves as a centralized portfolio of classification and regression models implemented using established machine learning frameworks.

The repository is structured to demonstrate proficiency in various machine learning algorithms, including Decision Trees, Random Forests, SVM, KNN, Linear/Logistic Regression, and Naive Bayes. Each model is implemented in a modular way, making it easy to understand, extend, and apply to different datasets.

### Classification Models
- Decision Tree Classification
- KNN Classification

- Naive Bayes Classification

### Regression Models

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/machine-learning-models.git
cd machine-learning-models
```

### 2. Create a virtual environment (optional but recommended)

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run a specific model

```bash
python models/classification/decision_tree_classification.py
```
